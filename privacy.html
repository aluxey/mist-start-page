Mist Start Page — Privacy Policy

Mist Start Page is a Chrome extension that replaces the Chrome New Tab page with a minimal, customizable start page.

Data stored locally

Mist stores the following data locally in the user's browser:

  • User display name
  • Theme preference
  • Shortcut groups and links
  • Visibility preferences
  • Local backup and restore preferences

This data stays on the user's device and is not sent to the developer.

Search

Mist uses the Chrome Search API to perform searches from the New Tab search bar with the user's default Chrome search provider.

Mist does not change, replace, or override the user's default search engine.

Weather

If the optional weather widget is enabled, Mist may use ipapi.co to estimate the user's approximate location from their IP address.

Mist then uses Open-Meteo to retrieve weather information for that approximate location.

Mist does not request precise browser geolocation permission.

Accounts and tracking

Mist does not require an account.

Mist does not track browsing history.

Mist does not collect analytics.

Mist does not sell user data.
